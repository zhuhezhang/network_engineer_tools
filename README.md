# 网络工程师工具

一款基于 Python 和 PySide6 开发的桌面运维工具集，面向网络工程师及需要进行日常网络排障的用户。应用将文本差异比较、IPv4 子网计算、批量连通性探测和网卡 IP 配置整合在统一界面中，并支持中英文界面切换。

- GitHub：https://github.com/zhuhezhang/network_engineer_tools
- Gitee：https://gitee.com/zhuhezhang/network_engineer_tools

## 功能介绍

### 文本对比

- 并排编辑和比较两份文本，清晰查看新增、删除和修改内容。
- 提供行号和字符级差异高亮，便于定位细节。
- 支持从不同编码的文本文件导入内容。
- 支持查找、查找下一个/上一个以及替换，可使用大小写匹配、全词匹配和正则表达式。
- 支持调整文本区域比例、字体缩放以及中英文界面切换。

### IP 地址计算

- 根据 IPv4 地址和掩码/前缀计算网络相关信息。
- 支持子网覆盖（汇总）计算和 VLSM 地址规划。
- 提供输入校验及结果展示，辅助地址规划和网络排障。

### 批量 Ping

- 可同时对多个 IP 地址或域名进行连通性探测，并按设定间隔持续检测。
- 实时查看成功/失败状态、丢包率和时延统计。
- 可调整探测并发数（默认 50，范围 1–500）。
- 失败目标使用浅红色高亮，表格列宽可根据需要调整。

### 网卡 IP 地址设置

- 查看本机网络适配器及其 IP 配置信息。
- 配置 IP 地址、子网掩码、网关和 DNS，支持 DHCP/手动配置相关操作。
- 可保存常用配置方案，方便在不同网络环境间切换。
- Windows 上修改网卡配置可能需要管理员权限；请确认配置正确后再应用。

### 界面与操作

- 支持简体中文和 English 界面。
- 支持全局字体缩放，并可使用 Ctrl（macOS 使用 Cmd）+ 鼠标滚轮调整。
- 主窗口侧边栏宽度可拖动调整；部分分割区域支持双击恢复默认比例。

## 环境要求

- Python 3.8 或更高版本
- pip
- Windows、Linux 或 macOS（网卡配置能力与系统平台相关）

## 安装依赖

在项目目录中运行：

```bash
python -m pip install PySide6 charset-normalizer icmplib
```

## 运行

```bash
python main.py
```

## 使用提示

- 批量 Ping 可输入多个目标，按页面提示设置探测间隔、超时和并发数后开始检测。
- 网卡 IP 配置会影响当前设备的网络连接。应用配置前建议先记录原有设置，并确保地址、掩码、网关和 DNS 参数符合当前网络环境。
- Linux 上如需创建虚拟环境，可使用 `python3 -m venv .venv`；Windows 可使用 `python -m venv .venv`。激活环境后再安装依赖。

## 打包

项目可使用 PyInstaller 或 Nuitka 打包。以下为基本示例，实际参数可根据运行平台和发布方式调整：

```bash
pyinstaller -F -w main.py
```

PySide6 应用也可以使用 Nuitka 构建；Windows 下可按项目需要配置 GUI 模式和产品信息。单文件模式可能被部分安全软件误报，发布前建议在目标环境充分测试。
